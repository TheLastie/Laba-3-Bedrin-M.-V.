# Lab 3 — Diagram as Code

**Русский** | [English](README.en.md)

Материалы лабораторной работы №3 на тему «Диаграмма как код». В репозитории находятся письменный отчёт и формулировка задания.

## Что находится в репозитории

- `Laba.md` содержит отчёт в формате Markdown.
- `Задание 14` хранит текст задания.

## Запуск и настройка

Откройте `Laba.md` в просмотрщике Markdown. Приложения для сборки в репозитории нет.

## Примечания

Это репозиторий с учебными материалами, а не программный пакет.
